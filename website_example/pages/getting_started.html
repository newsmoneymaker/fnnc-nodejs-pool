About the algorithm (yescrypt)

Fennec mines with yescrypt (N=4096, r=16, p=1): a memory-hard CPU algorithm over the 80-byte block header. The pool speaks the standard Bitcoin Stratum protocol (SegWit is active on this chain, blocks carry a witness commitment). Block time is about 2.5 minutes; the reward is 6.25 FNNC, halved every 1,176,055 blocks; the whole coinbase goes to miners (no masternode/devfee output).

  • Use poolpayminer (below): it knows yescryptr16 and speaks this pool's protocol.
  • yescrypt is a CPU algorithm: any modern CPU works, more threads/cores means more hashrate.

Software

  • poolpayminer (Windows x64 and Linux x86-64): source code (a downloads page for Fennec will follow shortly). A modified XMRig with yescrypt (yescryptr16) and TLS support. Fee 1% (1 minute in about 100), shown at start-up; details on the download page.
  • Wallet (to get your address): Fennec Core from the project (releases) or the web wallet.

Rewards and payments

  • Reward scheme: proportional with time weighting (older shares of a round weigh less).
  • Block rewards become spendable after 100 blocks (about 4 hours); the pool credits your balance after that.
  • Payments are ordinary FNNC transactions to your address. Everyone who is due is paid in one transaction per round, the network fee is shared by the paid miners.
  • Modes: prop:ADDRESS (shared reward, default) or solo:ADDRESS (the block finder takes the reward).

Об алгоритме (yescrypt)

Fennec майнится yescrypt (N=4096, r=16, p=1): процессорный алгоритм над 80-байтным заголовком блока. Пул работает по стандартному протоколу Bitcoin Stratum (в этой сети активен SegWit, блоки несут witness commitment). Время блока около 2,5 минут; награда 6,25 FNNC, делится пополам каждые 1 176 055 блоков; весь coinbase достаётся майнерам (мастернод/devfee нет).

  • Используйте poolpayminer (ниже): он знает yescryptr16 и работает по протоколу этого пула.
  • yescrypt это процессорный алгоритм: хватит любого современного процессора, больше потоков/ядер — больше хешрейт.

Программы

  • poolpayminer (Windows x64 и Linux x86-64): исходный код (страница загрузок для Fennec появится позже). Изменённый XMRig с yescrypt (yescryptr16) и поддержкой TLS. Комиссия 1% (1 минута из примерно 100), показывается при запуске; подробности на странице загрузок.
  • Кошелёк (чтобы получить адрес): Fennec Core от проекта (релизы) или веб-кошелёк.

Награды и выплаты

  • Схема наград: пропорциональная с учётом времени (старые шары раунда весят меньше).
  • Награда за блок становится доступной через 100 блоков (около 4 часов); после этого пул зачисляет её на ваш баланс.
  • Выплаты это обычные транзакции FNNC на ваш адрес. Все, кому пора платить, получают деньги одной транзакцией за раунд, комиссию сети делят между собой получатели.
  • Режимы: prop:АДРЕС (общая награда, по умолчанию) или solo:АДРЕС (награду забирает нашедший блок).
